# Hang Time Transport

Next.js is the primary development and Sites deployment build. It exports static files to `out/`. Run `npm ci`, then `npm run dev` for development or `npm run build` for a static export.

The Gatsby project in `gatsby/` is an alternate build using the same React page, Tailwind styles and artwork. From that directory, run `npm install` and `npm run build`.

To build and serve the primary site in Docker, run `docker build -t hang-time .` followed by `docker run --rm -p 8080:80 hang-time`.

The development quote form prepares details locally. A business destination is required to receive live inquiries. The truck is an illustration of the proposed livery. The site covers household and commercial moves, per the supplied portfolio.

The coverage map uses projected boundaries from US Atlas (Census Bureau cartographic boundaries). The route line is illustrative. The calculator uses user entered driving miles.
